# mcpbot

一台**你自己服务器**上的个人 AI 助手：浏览器打开就能聊，模型接你自己的 Ollama，工具接你自己的服务。

它存在的理由只有一条：**你想说的话，不必先交给一个你不掌控的公司。**

## 你其实一直在忍的那件事

公网大模型你早就用得上——账号、网速、订阅费都不是门槛。真正的门槛是内容本身：

- 深夜里那段没成形的想法，关于要不要辞掉这份工作、关于体检报告上那行字、关于一段正在塌掉的关系。打到一半，瞥见"对话内容可能用于改进服务"，你就删掉了。**于是最有价值的那部分使用，从来没有发生过。**
- 你交出去的东西去了哪儿，你其实说不清：存在谁的机房、存多久、谁会看到（自动摘要的、抽检的、客服工单里传阅的）、会不会进下一版模型的训练集、条款改了你会不会知道。
- 一旦和账号绑定，你的作息、你的犹豫、你的关系网就能被拼成一份画像。这不是被偷走的，是换取一句流畅回答时你自己付出去的价格。
- 想带它走、想让平台忘掉，你做不到。换一家服务，历史留在上一家。
- 每次开新会话还得重新交代"我是谁、我在纠结什么"。为了用一个助手，你先学会管理它的会话、上下文、"记忆"——工具变成了活儿。

mcpbot 换掉的就是这一头：**处理你文字的，是你自己机器上的一个进程**。模型是你拉的，磁盘是你挂的，备份是你拷的，删除键在你手里。你可以今天就把它连同数据目录一起删掉，并且知道这就真的没了。

## 你的话到底经过哪些地方

| 内容 | 会送到哪里 | 留在哪里 |
|------|-----------|----------|
| 你在聊天框里打的字 | 你配置的那一个推理地址（默认 `http://127.0.0.1:11434`，即你自己局域网内的 Ollama），附上有限的最近上下文 | 你指定的数据目录，明文 JSONL。拷走就是备份，删掉就是没了 |
| 站点授权 Key | 只在你的浏览器与你的服务器之间走；只存在于当前标签页，关掉即失效 | 配置目录下的 `mcpbot.yaml`，权限 600 |
| 上游凭据 | 只发给它对应的那一个地址，不会顺带附带 | 同上 |
| 业务工具调用 | 你自己接入的那个服务地址，凭据只对得上它自己的地址 | 同上 |
| 运行日志 | 不出这台机器。日志驱动的通知出站通道必须显式关闭才允许启动，否则拒绝启动 | 数据目录旁的 `mcpbot.log` |

**它给不了你的，也说清楚**：不内置 TLS（请套在你自己的反向代理后面）、不做磁盘静态加密、防不了能拿到那块盘的人、不宣称"绝对安全"。自托管改变的只有一件事——**处理方从别人变成你自己**，其余边界仍然需要你自己在部署层面负责。

## 适合谁

**适合**：已经有一台自己维护的服务器或家用机、愿意动手配置，并且正因为有些话不想交出去所以宁可自己搭一套的人。想要一个能长期延续、不用反复交代背景、能把草稿整理下去的私密空间。

**不适合**：把它当医疗诊断、心理治疗、法律或财务建议的替代品。话题可以涉及健康、关系、工作、财务，但它不承诺专业结论，也不替你判断现实决策的对错——是否采纳建议始终是你的判断。

**也不是**多用户产品：一个部署对应一个使用者，认证靠一张授权 Key，不做账号体系、不做租户隔离、不做管理控制台。

## 你能拿它做什么

- **把不敢说出口的事整理清楚**：零散的想法进来，一份你可以继续改的草稿出去，而你清楚这份东西此刻只在你自己的磁盘上。
- **接着上次说**：历史自动带出来，不必重讲背景。你也可以直接告诉它"以后回答简短些""我家里门锁代码是 1234"，让它沿用。
- **分得清建议和已经发生的事**：每条回答都带着它自己的结局——完成、失败还是中止，回答是否完整，有没有真正落盘。没确认的事不会被写成成功。
- **让它够得着你的东西**：把你自己的服务以 MCP Server 的形式挂进来，助手就能在对话里调用它们。（这条还在路上，见下）

## 现在能做什么，还做不到

当前进度 **M0**：认证 + 一次完整的非流式对话已经可用。

**已经可用**：授权 Key 登录 · 即时对话（自动带有限最近上下文）· 聊天历史落盘与网页分页回看 · 过程与结局反馈（接纳 → 生成 → 收尾 → 结束，并分别标出「回答完整/未完成」「已确认保存/未确认」）· 一次对话一个名额与一个总时限（默认 180 秒），断线后有界收尾 · Key 校验频率、请求体体积、历史分页与响应大小限额 · 启动前逐项自检，不过就拒绝启动并给出单行诊断 · 数据目录进程独占，避免两个进程同时写坏记录。

**还没做**：逐字流式呈现（回答目前整段返回）· MCP 工具接入与调用（配置段已就绪，接入逻辑未实现）· 记忆的保存/使用/修正（能延续上下文，不承诺长期记忆）· 按 token 预算自动裁剪上下文 · 手机端专门排版（能用，未做小屏优化）。

## 快速开始

前提：一台能常驻的机器，以及一个跑起来的 [Ollama](https://ollama.com)（先 `ollama pull` 一个模型）。

```bash
./setup.sh    # 建 Python 3.13 环境并装依赖（有 conda 用 conda，没有退回 venv）
./start.sh    # 首次运行会打印一次本站授权 Key
```

浏览器打开 `http://127.0.0.1:8100`，粘贴那把 Key。到此你已经有自己的助手了。

要从外面访问：设 `web.public_mode: true`，并把它放在你自己的反向代理后面（TLS 由代理终结）。工作目录默认与项目同级的 `../mcpbot-work`——配置、聊天记录、日志都在那里，和代码分开；首次运行按 `mcpbot.yaml.example` 生成配置、随机填入站点 Key（权限 600，只打印那一次）。所有可调项的取值区间就写在那份示例的注释里；`MCPBOT_WORKDIR` / `MCPBOT_CONDA_ENV` / `MCPBOT_MODEL` 分别改工作目录、环境名和默认模型。

## 技术信息

Python 3.13 单运行时 · FastAPI + uvicorn · 服务端模板 + 原生脚本（无前端构建步骤）· JSONL 文件记录域 + 进程独占锁 · httpx 对接 Ollama `/api/chat` 与 MCP Streamable HTTP。

- 模型不写死：推理侧完全交给 Ollama，配置里只填地址与模型标识。
- 工具不写死：能力由你自己的 MCP Server 提供，本站只做通用客户端，不再造一层 MCP 网关。
- `libs/wcore` 随仓库附带，是常驻服务的基础库（配置装载、启动核对、日志、凭据），本仓库不修改它。
- 代码与配置注释里的 `FR-xxx` / `CON-xxx` / `IF-xxx` 是需求与接口编号，用来把实现钉回对应条款。

```
src/mcpbot/        服务端
  app.py           装配与 HTTP 入口
  auth.py          站点凭据与入口限额
  orchestration.py 一次对话的执行状态机、名额与预算
  ollama.py        推理接入与完成证据判定
  history.py       聊天历史的保存与分页读取
  durable.py       落盘原语：追加与原子替换
  static/ templates/ 前端脚本与页面外壳
docs/              早期调研与已被取代的产品形态材料，仅作历史参考
```
